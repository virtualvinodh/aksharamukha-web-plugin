Aksharamukha Web Plugin — v5 Demo (lightweight)

This page loads aksharamukha-v5.js?engine=api — no WASM download, every conversion is a network call to the hosted API (the same lightweight behaviour v3/v4 had). Good for pages with light, occasional use or slow connections; see the default WASM demo for the offline-after-first-load alternative.
