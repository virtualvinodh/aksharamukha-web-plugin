Aksharamukha Web Plugin — v5 Demo

This page loads aksharamukha-v5.js with the default engine=auto, which runs the actual transliteration engine client-side via WASM (Pyodide) — no network call per conversion, only a one-time ~15-20s engine download on first use. Must be served over HTTP (not file://).

For pages with light, occasional use (or slow connections), embed with ?engine=api instead to skip the WASM download entirely and always call the hosted API — see the lightweight demo. See the README for the full explanation.
